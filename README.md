A collection of **54 SQL practice problems** designed to strengthen SQL fundamentals through real-world database scenarios.

This repository documents my personal learning journey by solving SQL exercises from the **Programming Advices SQL Course**. Every solution is written using **pure SQL queries**, focusing on mastering the language before moving on to advanced SQL Server programming.

---

# 📖 About This Repository

The purpose of this repository is to practice SQL by solving practical database problems that cover the most important concepts used in real-world applications and technical interviews.

The solutions are intentionally written without relying on advanced SQL Server programming features, allowing learners to focus on understanding SQL query logic and relational database concepts.
